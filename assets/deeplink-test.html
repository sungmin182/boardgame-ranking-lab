당근 앱이 열리는지 시험

각 버튼을 눌러보고 앱이 열리는지 / 웹이 열리는지만 알려주세요. 누른 뒤에는 뒤로가기로 돌아오시면 됩니다.

  1. 1. 글 링크 (그냥 주소) 앱이 열리면 → 크롬이 앱으로 넘겨주긴 한다는 뜻 눌러보기
  2. 2. 글 링크 (앱 강제 호출) 1번이 웹으로 열렸는데 이건 앱이 열리면 → 강제 호출 방식이 맞다는 뜻 눌러보기
  3. 3. 검색 (그냥 주소) 앱이 열리면 → 검색 경로도 앱이 받는다는 뜻 눌러보기
  4. 4. 검색 (앱 강제 호출) — 지금 사이트가 쓰는 방식 이게 앱으로 열려야 원하시는 동작이 됩니다 눌러보기
  5. 5. 앱만 열기 (주소 없이) 이거라도 되면 "이름 복사 + 앱 열기" 방식을 쓸 수 있습니다 눌러보기
  6. 6. 당근 첫 화면 (앱 강제 호출) 5번이 안 될 때의 대안 눌러보기
  7. 7. 앱 실행 (정식 방법) 앞의 5번은 제가 잘못 만든 형태였습니다. 이게 앱을 그냥 실행시키는 표준 방식입니다. 되면 "이름 복사 + 앱 실행"을 만들 수 있습니다. 눌러보기
  8. 8. 앱 실행 (더 단순한 형태) 7번이 안 될 때의 대안 눌러보기
알려주실 것
7·8번만 확인해 주세요. 앱인지 웹인지 (아무 일도 안 일어나면 무반응)

예) 7 앱 · 8 무반응
